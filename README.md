# gjsify.github.io

Organization site of [gjsify](https://github.com/gjsify), served at **https://gjsify.org**.

Its only job is the custom domain: every project site of the organization is published under it
automatically.

| URL | Source |
|---|---|
| https://gjsify.org/ | this repo — redirects to `/gjsify/` |
| https://gjsify.org/gjsify/ | [gjsify/gjsify](https://github.com/gjsify/gjsify) (`website/`) |
| https://gjsify.org/docs/ | [gjsify/docs](https://github.com/gjsify/docs) |
